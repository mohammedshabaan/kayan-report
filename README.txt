منشئ القرارات الإدارية — الإصدار المطور

تشغيل الموقع:
1) افتح ملف index.html في متصفح حديث مثل Chrome أو Edge.
2) عدّل النصوص والبيانات وسيتم تحديث التصميم تلقائيًا في المعاينة المباشرة.
3) يمكنك رفع صورتك الشخصية وضبط مكانها وتكبيرها بالماوس أو عبر شريط التحكم.
4) اضغط «تحميل التصميم PNG» للحصول على صورة فائقة الدقة (2508×2508 بكسل) أو خيارات التصدير الأخرى.

أبرز التحسينات والمميزات المضافة:
- تحسين رفع وتحرير الصورة الشخصية:
  * دعم السحب والإفلات (Drag & Drop) لأي ملف صورة.
  * معاينة مصغرة فورية لجميع الصور المرفوعة.
  * تحريك الصورة مباشرة بالنقر والسحب بالماوس فوق المعاينة.
  * أشرطة تحكم دقيقة: تكبير/تصغير (Zoom 50% - 250%)، تحريك رأسي، تحريك أفقي، وتدوير 90 درجة.
  * زر استعادة الصورة الأصلية بنقرة واحدة.

- تفريغ خلفيات التواقيع والشعارات تلقائيًا:
  * ميزة ذكية لإزالة الخلفية البيضاء من صور التواقيع والشعارات الورقية لتندمج كخلفية شفافة احترافية.

- خيارات تصدير وتحميل متعددة:
  * تحميل صورة PNG فائقة الدقة (2508×2508 بكسل) بألوان ملكية كحلي وذهبي، مثالية للطباعة.
  * تحميل صورة JPG خفيفة ومضغوطة للمشاركة السريعة عبر واتساب ومواقع التواصل.
  * زر «نسخ الصورة» لحفظ التصميم في الحافظة ولصقه مباشرة (Ctrl+V) في أي برنامج أو محادثة.
  * زر «طباعة / PDF» للطباعة الورقية أو حفظ مستند PDF مباشر.

- عمل كامل بدون إنترنت (Offline Ready):
  * تم دمج مكتبة html2canvas محليًا داخل مجلد assets لضمان التصدير حتى في حالة انقطاع الإنترنت.
  * تم تضمين الأصول الافتراضية بنظام Data URL لتجنب أي مشاكل أمان أو Tainted Canvas عند فتح الموقع من سطح المكتب مباشرة (ملف file://).

- الحفظ التلقائي المحلي:
  * حفظ تلقائي للبيانات والصور المرفوعة وإعدادات الزووم على جهازك عبر IndexedDB و LocalStorage لعدم ضياع أي تعديل عند تحديث الصفحة.
  * زر «إعادة ضبط النموذج» لمسح التعديلات والعودة للوضع الافتراضي عند الرغبة.
